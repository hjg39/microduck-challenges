# Metal (Apple GPU) training environment for microduck-challenges.
#
# The main .venv is locked to warp-lang 1.12 (CPU-only on macOS). The Apple
# Metal backend (warp-metal) overlays warp-lang 1.17, so it needs its own env.
#
# Verified on the M5 Max: the full MicroDuck sprint env runs on metal:0 and is
# ~6.4x faster than CPU at 2048 parallel envs (333 ms vs 2132 ms per step).
#
# Install:
#   uv venv .venv-metal --python 3.12
#   uv pip install --python .venv-metal/bin/python -r metal/requirements.txt
#   uv pip install --python .venv-metal/bin/python -e .
#   uv pip install --python .venv-metal/bin/python "warp-lang==1.17.0"
#   .venv-metal/bin/python metal/patch.py   # applies the two site-packages patches
#
# Train (the bridge routes physics to metal:0, torch tensors stay on cpu):
#   .venv-metal/bin/python -c "import metal.bridge" ... see metal/train_metal.sh
